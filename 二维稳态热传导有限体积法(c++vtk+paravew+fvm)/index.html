    1. 程序设计思路

    本程序用于求解二维稳态热传导问题。整体设计思路为：

    参数 → 网格 → 组装方程组 → Gauss-Seidel 求解 → 输出温度场

    程序先定义物理参数和计算区域，再对区域进行网格划分；随后根据有限体积法思想组装线性方程组，最后使用 Gauss-Seidel 迭代法求解温度场，并将结果保存为 VTK 文件，用于 ParaView 后处理可视化。

    2. 程序模块划分

    模块 作用
    namespace Heat2D 把二维传热相关代码包起来
    Grid2D 管理网格、编号、步长
    HeatParameters 管理物理参数
    DenseLinearSystem 存储线性方程组 (AX=b)
    SteadyHeatProblem 负责组装矩阵
    GaussSeidelSolver 负责迭代求解
    printField 输出二维温度场
    saveAsVTK 保存为 VTK 文件，供 ParaView 可视化

    3. 数学模型

    二维稳态热传导方程可以写为：

    \[ \nabla \cdot (k\nabla T)=0. \]

    当导热系数 (k) 为常数时，上式可以化为：

    \[ \Delta T=0. \]

    其中：

    • \(T\)：温度；
    • \(k\)：导热系数；
    • \(\Delta T\)：温度场的 Laplace 算子。

    4. 边界条件

    程序中主要包含三类边界条件。

    4.1 左边界：给定温度边界

    左边界给定温度，例如：

    \[ T=200. \]

    这表示左边界维持在较高温度。

    4.2 右边界：绝热边界

    右边界近似为绝热边界：

    \[ \frac{\partial T}{\partial n}=0. \]

    这表示边界法向方向没有热量流出。

    4.3 上下边界：第三类边界条件

    上下边界采用对流换热条件：

    \[ -k\frac{\partial T}{\partial n}=h(T_s-T_a). \]

    其中：

    • \(h\)：对流换热系数；
    • \(T_s\)：边界表面温度；
    • \(T_a\)：环境温度。

    程序中将边界表面温度写成内部节点温度的形式：

    \[ T_s=c_1T_p+c_2. \]

    其中：

    \[ c_1=\frac{2k}{2k+h\Delta y}, \]
    \[ c_2=\frac{T_a h\Delta y}{2k+h\Delta y}. \]

    5. 有限体积离散思想

    对于二维稳态导热问题，可以对一个控制体进行热流平衡：

    \[ q_E+q_W+q_N+q_S=0. \]

    对于内部节点 (P)，东西南北四个方向分别记为：

            N
        |
   W —— P —— E
        |
        S

    东侧热流近似为：

    \[ q_E=k\frac{T_E-T_P}{\Delta x}\Delta y. \]

    西侧热流近似为：

    \[ q_W=k\frac{T_W-T_P}{\Delta x}\Delta y. \]

    北侧热流近似为：

    \[ q_N=k\frac{T_N-T_P}{\Delta y}\Delta x. \]

    南侧热流近似为：

    \[ q_S=k\frac{T_S-T_P}{\Delta y}\Delta x. \]

    代入热流平衡，并约去常数 (k)，得到：

    \[ \frac{\Delta y}{\Delta x}(T_E-T_P) + \frac{\Delta y}{\Delta x}(T_W-T_P) + \frac{\Delta x}{\Delta y}(T_N-T_P) + \frac{\Delta x}{\Delta y}(T_S-T_P)=0. \]

    展开后得到内部节点的离散格式：

    \[ -\left( 2\frac{\Delta y}{\Delta x} + 2\frac{\Delta x}{\Delta y} \right)T_P + \frac{\Delta y}{\Delta x}T_E + \frac{\Delta y}{\Delta x}T_W + \frac{\Delta x}{\Delta y}T_N + \frac{\Delta x}{\Delta y}T_S =0. \]

    对应代码中的形式为：

    system.setA(p, p, -2.0 * dy / dx - 2.0 * dx / dy);
system.setA(p, grid_.index(row, col - 1), dy / dx);
system.setA(p, grid_.index(row, col + 1), dy / dx);
system.setA(p, grid_.index(row + 1, col), dx / dy);
system.setA(p, grid_.index(row - 1, col), dx / dy);

    6.3 Grid2D

    Grid2D 用于管理二维网格。

    主要功能包括：

    1. 保存 \(x\)、\(y\) 方向的网格数量；
    2. 计算网格步长 \(\Delta x\)、\(\Delta y\)；
    3. 实现二维编号到一维编号的转换。

    二维节点编号为：

    \[ (row,col) \]

    对应的一维编号为：

    \[ p=row\cdot nx+col. \]

    程序中写成：

    std::size_t index(std::size_t row, std::size_t col) const
{
    return row * nx_ + col;
}

    例如：

    std::size_t p = grid.index(row, col);

    p = row * nx + col;

    • \(A\)：系数矩阵；

    • \(b\)：右端项。

    程序中可以定义：

    using Vector = std::vector<double>;
using Matrix = std::vector<std::vector<double>>;

    Matrix A_;
Vector b_;

    对于 \(50\times 50\) 的网格，共有：

    \[ 2500 \]

    个未知量，因此矩阵规模为：

    \[ 2500\times 2500. \]

    6.6 GaussSeidelSolver

    GaussSeidelSolver 用于求解线性方程组：

    \[ AX=b. \]

    迭代过程可以写成：

    \[ x_i \leftarrow x_i+\frac{r_i}{A_{ii}}, \]

    其中残差为：

    \[ r_i=b_i-\sum_j A_{ij}x_j. \]

    程序中对应写法为：

    double residual = b[i];

for (std::size_t j = 0; j < n; ++j)
{
    residual -= A[i][j] * x[j];
}

x[i] += residual / A[i][i];

    7. 主程序

    int main()
{
    using namespace Heat2D;

    Grid2D grid(50, 50, 0.0, 0.1, 0.0, 0.1);

    HeatParameters params;
    params.conductivity = 205.0;
    params.convectionCoeff = 1000.0;
    params.ambientTemperature = 20.0;
    params.leftTemperature = 200.0;

    SteadyHeatProblem problem(grid, params);
    DenseLinearSystem system = problem.assemble();

    SolverConfig config;
    config.maxIterations = 20000;
    config.tolerance = 1e-3;
    config.printEvery = 100;
    config.verbose = true;

    GaussSeidelSolver solver(config);

    Vector temperature = solver.solve(system);

    saveAsVTK(temperature, grid, "temperature.vtk");

    return 0;
}

    SPACING dx dy 1 表示网格间距
    POINT_DATA nx*ny 表示点数据个数
    SCALARS Temperature double 1 表示温度是标量数据

    12. 总结

    本程序实现了二维稳态热传导问题的数值求解。程序采用有限体积法思想进行离散，将偏微分方程转化为线性方程组：

    \[ AX=b. \]

    随后使用 Gauss-Seidel 迭代法求解温度分布，并将结果保存为 VTK 文件，用于 ParaView 可视化。

    整体程序结构为：

    参数 → 网格 → 组装方程组 → Gauss-Seidel 求解 → 输出温度场

namespace Heat2D {
using Vector = std::vector<double>;
using Matrix = std::vector<std::vector<double>>;
// =========================
// 1. 物理参数
// =========================
struct HeatParameters {
  double conductivity = 205.0;       // 导热系数 k
  double convectionCoeff = 1000.0;   // 对流换热系数 h
  double ambientTemperature = 20.0;  // 环境温度 Ta
  double leftTemperature = 200.0;    // 左边界温度
};
// =========================
// 2. 二维网格类
// =========================
class Grid2D {
 public:
  Grid2D(std::size_t nx, std::size_t ny, double xLeft, double xRight,
         double yBottom, double yTop)
      : nx_(nx),
        ny_(ny),
        xLeft_(xLeft),
        xRight_(xRight),
        yBottom_(yBottom),
        yTop_(yTop) {
    if (nx_ < 2 || ny_ < 2) {
      throw std::runtime_error("网格数量 nx 和 ny 必须大于等于 2");
    }

    dx_ = (xRight_ - xLeft_) / static_cast<double>(nx_);
    dy_ = (yTop_ - yBottom_) / static_cast<double>(ny_);
  }

  std::size_t nx() const { return nx_; }//
  std::size_t ny() const { return ny_; }
  std::size_t size() const { return nx_ * ny_; }

  double dx() const { return dx_; }
  double dy() const { return dy_; }

  // 二维编号转换为一维编号
  std::size_t index(std::size_t row, std::size_t col) const {
    return row * nx_ + col;
  }

 private:
  std::size_t nx_;
  std::size_t ny_;

  double xLeft_;
  double xRight_;
  double yBottom_;
  double yTop_;

  double dx_;
  double dy_;
};
///可视化工具paraview+vtk
void saveAsVTK(const Vector& temperature, const Grid2D& grid,
               const std::string& filename) {
  std::ofstream fout(filename);

  if (!fout) {
    throw std::runtime_error("无法创建 VTK 文件");
  }

  std::size_t nx = grid.nx();
  std::size_t ny = grid.ny();

  fout << "# vtk DataFile Version 3.0\n";
  fout << "二维热传导\n";
  fout << "ASCII\n";
  fout << "DATASET STRUCTURED_POINTS\n";

  fout << "DIMENSIONS " << nx << " " << ny << " " << 1 << "\n";

  fout << "ORIGIN 0 0 0\n";

  fout << "SPACING " << grid.dx() << " " << grid.dy() << " " << 1.0 << "\n";

  fout << "POINT_DATA " << nx * ny << "\n";
  fout << "SCALARS Temperature double 1\n";
  fout << "LOOKUP_TABLE default\n";

  for (std::size_t row = 0; row < ny; ++row) {
    for (std::size_t col = 0; col < nx; ++col) {
      std::size_t p = grid.index(row, col);
      fout << temperature[p] << "\n";
    }
  }

  fout.close();
}
// =========================
// 3. 稠密线性方程组 AX = b，小矩阵才行，大矩阵稀疏，
// =========================
class DenseLinearSystem {
 public:
  explicit DenseLinearSystem(std::size_t n)
      : A_(n, Vector(n, 0.0)), b_(n, 0.0) {}

  std::size_t size() const { return b_.size(); }

  void setA(std::size_t i, std::size_t j, double value) { A_[i][j] = value; }

  void setB(std::size_t i, double value) { b_[i] = value; }

  const Matrix& A() const { return A_; }

  const Vector& b() const { return b_; }

 private:
  Matrix A_;
  Vector b_;
};

// =========================
// 4. 利用Gauss-Seidel 求解器
// =========================
struct SolverConfig {
  std::size_t maxIterations = 20000;
  double tolerance = 1e-3;
  std::size_t printEvery = 100;
  bool verbose = true;
};

class GaussSeidelSolver {
 public:
  explicit GaussSeidelSolver(SolverConfig config) : config_(config) {}

  Vector solve(const DenseLinearSystem& system) const {
    const Matrix& A = system.A();
    const Vector& b = system.b();

    std::size_t n = system.size();
    Vector x(n, 0.0);

    for (std::size_t iter = 0; iter < config_.maxIterations; ++iter) {
      double residualNorm = 0.0;

      for (std::size_t i = 0; i < n; ++i) {
        if (std::abs(A[i][i]) < 1e-14) {
          throw std::runtime_error(
              "矩阵对角线出现零元素，无法进行 Gauss-Seidel 迭代");
        }

        double residual = b[i];

        for (std::size_t j = 0; j < n; ++j) {
          if (A[i][j] == 0.0) {
            continue;
          }

          residual -= A[i][j] * x[j];
        }

        x[i] += residual / A[i][i];

        residualNorm += std::abs(residual);
      }

      if (config_.verbose && iter % config_.printEvery == 0) {
        std::cout << "迭代次数: " << iter << ", 残差: " << residualNorm << '\n';
      }

      if (residualNorm < config_.tolerance) {
        if (config_.verbose) {
          std::cout << "求解已收敛，迭代次数: " << iter
                    << ", 残差: " << residualNorm << '\n';
        }

        break;
      }
    }

    return x;
  }

 private:
  SolverConfig config_;
};

// =========================
// 5. 二维稳态导热问题
// =========================
class SteadyHeatProblem {
 public:
  SteadyHeatProblem(Grid2D grid, HeatParameters params)
      : grid_(grid), params_(params) {}

  DenseLinearSystem assemble() const {
    DenseLinearSystem system(grid_.size());

    assembleLeftBoundary(system);
    assembleRightBoundary(system);
    assembleTopBoundary(system);
    assembleBottomBoundary(system);
    assembleCorners(system);
    assembleInterior(system);

    return system;
  }

  const Grid2D& grid() const { return grid_; }

 private:
  Grid2D grid_;
  HeatParameters params_;

 private:
  double convectionC1() const {
    double k = params_.conductivity;
    double h = params_.convectionCoeff;
    double dy = grid_.dy();

    return 2.0 * k / (2.0 * k + h * dy);
  }

  double convectionC2() const {
    double k = params_.conductivity;
    double h = params_.convectionCoeff;
    double Ta = params_.ambientTemperature;
    double dy = grid_.dy();

    return Ta * h * dy / (2.0 * k + h * dy);
  }
// 左边界：给定温度
void assembleLeftBoundary(DenseLinearSystem& system) const {
    std::size_t nx = grid_.nx();
    std::size_t ny = grid_.ny();

    double dx = grid_.dx();
    double dy = grid_.dy();
    double TLeft = params_.leftTemperature;

    for (std::size_t row = 1; row < ny - 1; ++row) {
      std::size_t p = grid_.index(row, 0);

      system.setA(p, p, -(3.0 * dy / dx + 2.0 * dx / dy));
      system.setA(p, grid_.index(row, 1), dy / dx);
      system.setA(p, grid_.index(row + 1, 0), dx / dy);
      system.setA(p, grid_.index(row - 1, 0), dx / dy);

      system.setB(p, -TLeft * dy / dx);
    }
  }
// 右边界：近似绝热边界
  void assembleRightBoundary(DenseLinearSystem& system) const {
    std::size_t nx = grid_.nx();
    std::size_t ny = grid_.ny();

    double dx = grid_.dx();
    double dy = grid_.dy();

    for (std::size_t row = 1; row < ny - 1; ++row) {
      std::size_t p = grid_.index(row, nx - 1);

      system.setA(p, p, -(dy / dx + 2.0 * dx / dy));
      system.setA(p, grid_.index(row, nx - 2), dy / dx);
      system.setA(p, grid_.index(row + 1, nx - 1), dx / dy);
      system.setA(p, grid_.index(row - 1, nx - 1), dx / dy);

      system.setB(p, 0.0);
    }
  }
// 上边界：（三）对流换热边界
  void assembleTopBoundary(DenseLinearSystem& system) const {
    std::size_t nx = grid_.nx();
    std::size_t ny = grid_.ny();

    double dx = grid_.dx();
    double dy = grid_.dy();

    double c1 = convectionC1();
    double c2 = convectionC2();

    std::size_t row = ny - 1;

    for (std::size_t col = 1; col < nx - 1; ++col) {
      std::size_t p = grid_.index(row, col);

      system.setA(p, p, -(2.0 * dy / dx - (2.0 * c1 - 3.0) * dx / dy));
      system.setA(p, grid_.index(row, col - 1), dy / dx);
      system.setA(p, grid_.index(row, col + 1), dy / dx);
      system.setA(p, grid_.index(row - 1, col), dx / dy);

      system.setB(p, -2.0 * c2 * dx / dy);
    }
  }
// 下边界：对流换热边界
  void assembleBottomBoundary(DenseLinearSystem& system) const {
    std::size_t nx = grid_.nx();

    double dx = grid_.dx();
    double dy = grid_.dy();

    double c1 = convectionC1();
    double c2 = convectionC2();

    std::size_t row = 0;

    for (std::size_t col = 1; col < nx - 1; ++col) {
      std::size_t p = grid_.index(row, col);

      system.setA(p, p, -(2.0 * dy / dx - (2.0 * c1 - 3.0) * dx / dy));
      system.setA(p, grid_.index(row, col - 1), dy / dx);
      system.setA(p, grid_.index(row, col + 1), dy / dx);
      system.setA(p, grid_.index(row + 1, col), dx / dy);

      system.setB(p, -2.0 * c2 * dx / dy);
    }
  }
// 四角点
  void assembleCorners(DenseLinearSystem& system) const {
    std::size_t nx = grid_.nx();
    std::size_t ny = grid_.ny();

    double dx = grid_.dx();
    double dy = grid_.dy();

    double TLeft = params_.leftTemperature;
    double c1 = convectionC1();
    double c2 = convectionC2();

    // 左下角
    {
      std::size_t p = grid_.index(0, 0);

      system.setA(p, p, -(3.0 * dy / dx - (2.0 * c1 - 3.0) * dx / dy));
      system.setA(p, grid_.index(0, 1), dy / dx);
      system.setA(p, grid_.index(1, 0), dx / dy);

      system.setB(p, -TLeft * dy / dx - 2.0 * c2 * dx / dy);
    }

    // 右下角
    {
      std::size_t p = grid_.index(0, nx - 1);

      system.setA(p, p, -(dy / dx - (2.0 * c1 - 3.0) * dx / dy));
      system.setA(p, grid_.index(0, nx - 2), dy / dx);
      system.setA(p, grid_.index(1, nx - 1), dx / dy);

      system.setB(p, -2.0 * c2 * dx / dy);
    }

    // 左上角
    {
      std::size_t p = grid_.index(ny - 1, 0);

      system.setA(p, p, -(3.0 * dy / dx - (2.0 * c1 - 3.0) * dx / dy));
      system.setA(p, grid_.index(ny - 1, 1), dy / dx);
      system.setA(p, grid_.index(ny - 2, 0), dx / dy);

      system.setB(p, -TLeft * dy / dx - 2.0 * c2 * dx / dy);
    }

    // 右上角
    {
      std::size_t p = grid_.index(ny - 1, nx - 1);

      system.setA(p, p, -(dy / dx - (2.0 * c1 - 3.0) * dx / dy));
      system.setA(p, grid_.index(ny - 1, nx - 2), dy / dx);
      system.setA(p, grid_.index(ny - 2, nx - 1), dx / dy);

      system.setB(p, -2.0 * c2 * dx / dy);
    }
  }

  // 内部节点
  void assembleInterior(DenseLinearSystem& system) const {
    std::size_t nx = grid_.nx();
    std::size_t ny = grid_.ny();

    double dx = grid_.dx();
    double dy = grid_.dy();

    for (std::size_t row = 1; row < ny - 1; ++row) {
      for (std::size_t col = 1; col < nx - 1; ++col) {
        std::size_t p = grid_.index(row, col);

        system.setA(p, p, -2.0 * dy / dx - 2.0 * dx / dy);
        system.setA(p, grid_.index(row, col - 1), dy / dx);
        system.setA(p, grid_.index(row, col + 1), dy / dx);
        system.setA(p, grid_.index(row + 1, col), dx / dy);
        system.setA(p, grid_.index(row - 1, col), dx / dy);

        system.setB(p, 0.0);
      }
    }
  }
};

// =========================
// 6. 输出温度场
// =========================
void printField(const Vector& temperature, const Grid2D& grid) {
  std::size_t nx = grid.nx();
  std::size_t ny = grid.ny();

  std::cout << "\n温度场结果:\n";

  for (std::size_t row = 0; row < ny; ++row) {
    for (std::size_t col = 0; col < nx; ++col) {
      std::size_t p = grid.index(row, col);

      std::cout << std::setw(10) << std::fixed << std::setprecision(3)
                << temperature[p] << ' ';
    }

    std::cout << '\n';
  }
}

}  // namespace Heat2D

int main() {
  try {
    using namespace Heat2D;

    // =========================
    // 1. 定义网格
    // =========================
    Grid2D grid(50,   // x 方向网格数量
                50,   // y 方向网格数量
                0.0,  // xLeft
                0.1,  // xRight
                0.0,  // yBottom
                0.1   // yTop
    );

    // =========================
    // 2. 定义物理参数
    // =========================
    HeatParameters params;
    params.conductivity = 205.0;
    params.convectionCoeff = 1000.0;
    params.ambientTemperature = 20.0;
    params.leftTemperature = 200.0;

    // =========================
    // 3. 组装问题
    // =========================
    SteadyHeatProblem problem(grid, params);
    DenseLinearSystem system = problem.assemble();

    // =========================
    // 4. 设置求解器
    // =========================
    SolverConfig config;
    config.maxIterations = 20000;
    config.tolerance = 1e-3;
    config.printEvery = 100;
    config.verbose = true;

    GaussSeidelSolver solver(config);

    // =========================
    // 5. 求解
    // =========================
    auto start = std::chrono::high_resolution_clock::now();

    Vector temperature = solver.solve(system);

    auto end = std::chrono::high_resolution_clock::now();

    std::chrono::duration<double> elapsed = end - start;

    std::cout << "\n计算用时: " << elapsed.count() << " 秒\n";

    // =========================
    // 6. 输出结果
    // =========================
    printField(temperature, grid);
    saveAsVTK(temperature, grid, "temperature.vtk");
    std::cout << "结果已保存到 temperature.vtk\n";

  } catch (const std::exception& e) {
    std::cerr << "程序错误: " << e.what() << '\n';
    return 1;
  }

  return 0;
}
