    二维稳态热传导有限体积法程序展示

    1. 程序设计思路

    本程序用于求解二维稳态热传导问题。整体设计思路为：

    参数 → 网格 → 组装方程组 → Gauss-Seidel 求解 → 输出温度场

    程序先定义物理参数和计算区域，再对区域进行网格划分；随后根据有限体积法思想组装线性方程组，最后使用 Gauss-Seidel 迭代法求解温度场，并将结果保存为 VTK 文件，用于 ParaView 后处理可视化。

    2. 程序模块划分

    模块 作用
    namespace Heat2D 把二维传热相关代码包起来
    Grid2D 管理网格、编号、步长
    HeatParameters 管理物理参数
    DenseLinearSystem 存储线性方程组 (AX=b)
    SteadyHeatProblem 负责组装矩阵
    GaussSeidelSolver 负责迭代求解
    printField 输出二维温度场
    saveAsVTK 保存为 VTK 文件，供 ParaView 可视化

    3. 数学模型

    二维稳态热传导方程可以写为：

    [ \nabla \cdot (k\nabla T)=0. ]

    当导热系数 (k) 为常数时，上式可以化为：

    [ \Delta T=0. ]

    其中：

    • (T)：温度；
    • (k)：导热系数；
    • (\Delta T)：温度场的 Laplace 算子。

    本程序主要求解一个二维矩形区域中的稳态温度分布。

    4. 边界条件

    程序中主要包含三类边界条件。

    4.1 左边界：给定温度边界

    左边界给定温度，例如：

    [ T=200. ]

    这表示左边界维持在较高温度。

    4.2 右边界：绝热边界

    右边界近似为绝热边界：

    [ \frac{\partial T}{\partial n}=0. ]

    这表示边界法向方向没有热量流出。

    4.3 上下边界：第三类边界条件

    上下边界采用对流换热条件：

    [ -k\frac{\partial T}{\partial n}=h(T_s-T_a). ]

    其中：

    • (h)：对流换热系数；
    • (T_s)：边界表面温度；
    • (T_a)：环境温度。

    程序中将边界表面温度写成内部节点温度的形式：

    [ T_s=c_1T_p+c_2. ]

    其中：

    [ c_1=\frac{2k}{2k+h\Delta y}, ]

    [ c_2=\frac{T_a h\Delta y}{2k+h\Delta y}. ]

    5. 有限体积离散思想

    对于二维稳态导热问题，可以对一个控制体进行热流平衡：

    [ q_E+q_W+q_N+q_S=0. ]

    对于内部节点 (P)，东西南北四个方向分别记为：

            N
        |
   W —— P —— E
        |
        S

    东侧热流近似为：

    [ q_E=k\frac{T_E-T_P}{\Delta x}\Delta y. ]

    西侧热流近似为：

    [ q_W=k\frac{T_W-T_P}{\Delta x}\Delta y. ]

    北侧热流近似为：

    [ q_N=k\frac{T_N-T_P}{\Delta y}\Delta x. ]

    南侧热流近似为：

    [ q_S=k\frac{T_S-T_P}{\Delta y}\Delta x. ]

    代入热流平衡，并约去常数 (k)，得到：

    [ \frac{\Delta y}{\Delta x}(T_E-T_P) + \frac{\Delta y}{\Delta x}(T_W-T_P) + \frac{\Delta x}{\Delta y}(T_N-T_P) + \frac{\Delta x}{\Delta y}(T_S-T_P)=0. ]

    展开后得到内部节点的离散格式：

    [ -\left( 2\frac{\Delta y}{\Delta x} + 2\frac{\Delta x}{\Delta y} \right)T_P + \frac{\Delta y}{\Delta x}T_E + \frac{\Delta y}{\Delta x}T_W + \frac{\Delta x}{\Delta y}T_N + \frac{\Delta x}{\Delta y}T_S =0. ]

    对应代码中的形式为：

    K[i][i]      = -2.0 * dy / dx - 2.0 * dx / dy;
K[i][i - 1]  = dy / dx;
K[i][i + 1]  = dy / dx;
K[i][i + hx] = dx / dy;
K[i][i - hx] = dx / dy;

    该格式在规则矩形网格上与有限差分五点格式等价，但由于系数具有“面积/距离”的形式，因此更接近有限体积法的写法。

    6. 类与函数设计

    6.1 namespace Heat2D

    使用命名空间把二维热传导程序相关的类和函数组织起来，避免与其他程序发生命名冲突。

    namespace Heat2D
{
    // 网格、参数、方程组、求解器等代码
}

    主程序中可以写：

    using namespace Heat2D;

    这样可以让代码结构更加清晰。

    6.2 HeatParameters

    HeatParameters 用于集中管理物理参数。

    struct HeatParameters
{
    double conductivity = 205.0;
    double convectionCoeff = 1000.0;
    double ambientTemperature = 20.0;
    double leftTemperature = 200.0;
};

    含义如下：

    变量 含义
    conductivity 导热系数 (k)
    convectionCoeff 对流换热系数 (h)
    ambientTemperature 环境温度 (T_a)
    leftTemperature 左边界给定温度

    这样做的好处是物理参数集中管理，后续修改更加方便。

    6.3 Grid2D

    Grid2D 用于管理二维网格。

    主要功能包括：

    1. 保存 (x)、(y) 方向的网格数量；
    2. 计算网格步长 (\Delta x)、(\Delta y)；
    3. 实现二维编号到一维编号的转换。

    二维节点编号为：

    [ (row,col) ]

    对应的一维编号为：

    [ p=row\cdot nx+col. ]

    程序中写成：

    std::size_t index(std::size_t row, std::size_t col) const
{
    return row * nx_ + col;
}

    例如：

    std::size_t p = grid.index(row, col);

    这样可以避免在程序中反复手写：

    p = row * nx + col;

    代码可读性更好。

    6.4 DenseLinearSystem

    DenseLinearSystem 用于存储线性方程组：

    [ AX=b. ]

    其中：

    • (A)：系数矩阵；
    • (x)：待求温度向量；
    • (b)：右端项。

    程序中可以定义：

    using Vector = std::vector<double>;
using Matrix = std::vector<std::vector<double>>;

    然后使用：

    Matrix A_;
Vector b_;

    对于 (50\times 50) 的网格，共有：

    [ 2500 ]

    个未知量，因此矩阵规模为：

    [ 2500\times 2500. ]

    需要注意的是，目前使用的是稠密矩阵。对于更大规模问题，后续应改为稀疏矩阵存储。

    6.5 SteadyHeatProblem

    SteadyHeatProblem 是程序的核心类，负责根据物理模型和边界条件组装线性方程组。

    其主要功能包括：

    assembleLeftBoundary(system);
assembleRightBoundary(system);
assembleTopBoundary(system);
assembleBottomBoundary(system);
assembleCorners(system);
assembleInterior(system);

    分别表示：

    函数 作用
    assembleLeftBoundary 组装左边界方程
    assembleRightBoundary 组装右边界方程
    assembleTopBoundary 组装上边界方程
    assembleBottomBoundary 组装下边界方程
    assembleCorners 组装四个角点方程
    assembleInterior 组装内部节点方程

    这样做可以把不同位置的离散方程分开处理，边界条件更加清楚。

    6.6 GaussSeidelSolver

    GaussSeidelSolver 用于求解线性方程组：

    [ AX=b. ]

    迭代过程可以写成：

    [ x_i \leftarrow x_i+\frac{r_i}{A_{ii}}, ]

    其中残差为：

    [ r_i=b_i-\sum_j A_{ij}x_j. ]

    程序中对应写法为：

    double residual = b[i];

for (std::size_t j = 0; j < n; ++j)
{
    residual -= A[i][j] * x[j];
}

x[i] += residual / A[i][i];

    因为 Gauss-Seidel 方法会立即使用已经更新的分量，所以通常比 Jacobi 迭代收敛更快。

    7. 主程序流程

    主程序可以写成：

    int main()
{
    using namespace Heat2D;

    Grid2D grid(50, 50, 0.0, 0.1, 0.0, 0.1);

    HeatParameters params;
    params.conductivity = 205.0;
    params.convectionCoeff = 1000.0;
    params.ambientTemperature = 20.0;
    params.leftTemperature = 200.0;

    SteadyHeatProblem problem(grid, params);
    DenseLinearSystem system = problem.assemble();

    SolverConfig config;
    config.maxIterations = 20000;
    config.tolerance = 1e-3;
    config.printEvery = 100;
    config.verbose = true;

    GaussSeidelSolver solver(config);

    Vector temperature = solver.solve(system);

    saveAsVTK(temperature, grid, "temperature.vtk");

    return 0;
}

    程序流程可以概括为：

    定义网格
    ↓
定义物理参数
    ↓
组装离散方程组
    ↓
Gauss-Seidel 迭代求解
    ↓
保存温度场结果

    8. 结果输出与 ParaView 可视化

    工程计算中，不建议只使用 cout 输出全部结果。

    更规范的做法是将结果保存为文件，然后使用后处理软件查看，例如 ParaView。

    本程序推荐保存为 VTK 文件：

    saveAsVTK(temperature, grid, "temperature.vtk");

    程序运行后生成：

    temperature.vtk

    然后可以使用 ParaView 打开，显示温度云图。

    9. VTK 文件格式说明

    VTK 文件头部示例如下：

    fout << "# vtk DataFile Version 3.0\n";
fout << "2D heat conduction\n";
fout << "ASCII\n";
fout << "DATASET STRUCTURED_POINTS\n";
fout << "DIMENSIONS " << nx << " " << ny << " " << 1 << "\n";
fout << "ORIGIN 0 0 0\n";
fout << "SPACING " << grid.dx() << " " << grid.dy() << " " << 1.0 << "\n";
fout << "POINT_DATA " << nx * ny << "\n";
fout << "SCALARS Temperature double 1\n";
fout << "LOOKUP_TABLE default\n";

    各字段含义如下：

    字段 作用
    DATASET STRUCTURED_POINTS 表示规则结构网格
    DIMENSIONS nx ny 1 表示网格点数量
    ORIGIN 0 0 0 表示坐标起点
    SPACING dx dy 1 表示网格间距
    POINT_DATA nx*ny 表示点数据个数
    SCALARS Temperature double 1 表示温度是标量数据

    需要注意：

    • DIMENSIONS 必须与网格点数一致；
    • POINT_DATA 必须与输出的数据数量一致；
    • SPACING 应该使用真实的网格步长；
    • 变量名 Temperature 可以修改，但不建议使用中文。

    10. 程序特点

    本程序具有以下特点：

    1. 物理参数集中管理；
    2. 网格编号统一由 Grid2D 管理；
    3. 方程组装与求解过程分离；
    4. 边界条件分函数处理，结构清晰；
    5. 支持保存为 VTK 文件，便于 ParaView 可视化；
    6. 后续可以继续扩展为稀疏矩阵版本。

    11. 后续改进方向

    11.1 稀疏矩阵存储

    二维稳态热传导问题中，每个内部节点只与上下左右四个节点相连，因此矩阵中大部分元素为零。

    后续可以改为稀疏矩阵存储，以减少内存消耗。

    11.2 SOR 加速迭代

    Gauss-Seidel 方法可以进一步推广为 SOR 方法：

    [ x_i^{new} =========

    (1-\omega)x_i^{old} + \omega x_i^{GS}. ]

    其中 (\omega) 为松弛因子。适当选择 (\omega) 可以加快收敛速度。

    11.3 增加更多边界条件

    后续可以继续支持：

    • 第一类边界条件：给定温度；
    • 第二类边界条件：给定热流；
    • 第三类边界条件：对流换热。

    12. 总结

    本程序实现了二维稳态热传导问题的数值求解。程序采用有限体积法思想进行离散，将偏微分方程转化为线性方程组：

    [ AX=b. ]

    随后使用 Gauss-Seidel 迭代法求解温度分布，并将结果保存为 VTK 文件，用于 ParaView 可视化。

    整体程序结构为：

    参数 → 网格 → 组装方程组 → Gauss-Seidel 求解 → 输出温度场

    相比原始代码，重构后的版本结构更加清晰，便于后续修改边界条件、替换求解器以及扩展可视化输出。
