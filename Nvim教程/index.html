    Neovide + WSL 使用笔记

    🚀 启动 Neovide（WSL 模式）

    最基础、标准的启动命令（注意是两个减号）：

    neovide --wsl

    打开当前目录

    neovide --wsl .

    打开指定文件

    neovide --wsl path/to/your/file

    NvimTree 关闭与切换笔记

    方法一：使用命令

    :NvimTreeClose

    方法二：使用快捷键 （默认是 Ctrl + n，可以在配置文件中修改）

    :e ~/.config/nvim/init.lua
-- 在 init.lua 中添加以下配置来修改快捷键

    vim.keymap.set('n', '<leader>e', ':NvimTreeToggle<CR>', { desc = "Toggle NvimTree" })

    说明

    • <leader> 默认是空格键
    • <leader>e 表示按下「空格 + e」
    • <CR> 表示自动执行回车
    • n 表示在普通模式下生效

    使用效果

    配置完成并重启 Neovim 后：

    • 按「空格 + e」打开文件树
    • 再按一次「空格 + e」关闭文件树

    自动补全快捷键

    👇 Ctrl + n    向下选择（Next）
👆 Ctrl + p    向上选择（Previous）

    Neovim 复制粘贴笔记

    常见误区

    在 Neovim（Vim 家族）中：

    • Ctrl + C 不能用于复制（用于中断操作）
    • Ctrl + V 不能用于粘贴（用于进入块选择模式）

    核心法则：Yank & Put

    • 复制：y（Yank）
    • 粘贴：p（Put）

    如何复制

    1. 按 v 进入可视模式
2. 移动光标选择内容（h / j / k / l 或方向键）
3. 按 y 复制

    如何粘贴

    1. 按 v 进入可视模式
2. 移动光标选择内容（h / j / k / l 或方向键）
3. 按 p 粘贴

    常用技巧

    • 复制整行：yy
    • 复制多行：3yy（复制当前行及下面两行）
    • 粘贴到当前行上方：P
    • 粘贴到当前行下方：p
    • 复制到系统剪贴板（需要配置支持）："+y（复制）和 "+p（粘贴）
    • 撤销操作：u
    • 重做操作：Ctrl + r
    • 删除文本（同时复制到寄存器）：d（例如 dd 删除整行）
    • 替换文本：r（例如 rX 将光标所在字符替换为 X）
    • 进入块选择模式：Ctrl + v（用于选择矩形区域）
    • 进入行选择模式：V（用于选择整行）
    • 进入块选择模式后，使用方向键选择区域，然后按 y 复制或 d 删除
    • 使用寄存器："a（选择寄存器 a），例如 "ayy 将当前行复制到寄存器 a，之后可以使用 "ap 从寄存器 a 粘贴
    • 使用寄存器查看：:registers（显示所有寄存器内容）
    • 使用寄存器删除："ad（将删除的内容存储到
    • 寄存器 a，例如 "add 删除当前行并存储到寄存器 a）

    • 使用寄存器粘贴到当前行上方："aP

    Neovim 内置终端使用笔记

    1. 打开终端（原生命令）

    在 Neovim 中，可以直接使用原生命令打开终端。

    当前窗口打开终端

    :term
    • 在当前窗口直接打开终端
    • 会覆盖当前正在查看的代码窗口

    横向分屏打开终端

    :split | term
    • 横向分屏
    • 在下方打开终端

    纵向分屏打开终端

    :vsplit | term
    • 纵向分屏
    • 在右侧打开终端

    底部固定高度打开终端

    :botright 10split | term
    • 在最下方打开终端
    • 终端高度固定为 10 行
    • 常用于 C++ 调试布局

    2. 终端与代码之间切换

    打开终端后，需要区分两种模式：

    • 终端输入模式
    • 普通模式

    很多新手打开终端后无法退出，是因为仍然停留在终端输入模式中。

    进入终端输入模式

    i

    或：

    a
    • 点击终端窗口
    • 按 i 或 a
    • 可以像普通终端一样输入命令

    退出终端输入模式

    Ctrl + \  →  Ctrl + n
    • 先按 Ctrl + \
    • 再按 Ctrl + n
    • 即可回到普通模式

    回到普通模式后的操作

    只有回到普通模式后，才能使用窗口命令。

    Ctrl + w
    • 用于切换窗口
    :q
    • 用于关闭终端窗口

    3. 配置一键呼出终端（推荐）

    如果经常使用终端，可以在 init.lua 中设置快捷键。

    打开配置文件：

    :e ~/.config/nvim/init.lua

    加入以下配置：

    -- 空格 + t 快速在下方打开终端
vim.keymap.set('n', '<leader>t', ':botright 10split | term<CR>', { desc = '打开底部终端' })

-- 在终端里按 Esc 直接退回到普通模式
vim.keymap.set('t', '<Esc>', [[<C-\><C-n>]], { desc = '退出终端输入模式' })

    4. 配置说明

    打开底部终端

    vim.keymap.set('n', '<leader>t', ':botright 10split | term<CR>', { desc = '打开底部终端' })
    • n 表示普通模式
    • <leader>t 表示按下「空格 + t」
    • :botright 10split | term<CR> 表示在底部打开一个 10 行高度的终端
    • <CR> 表示自动回车执行命令

    退出终端输入模式

    vim.keymap.set('t', '<Esc>', [[<C-\><C-n>]], { desc = '退出终端输入模式' })
    • t 表示终端模式
    • <Esc> 表示按下 Esc 键
    • <C-\><C-n> 表示退出终端输入模式
    • 配置后不需要再手动按 Ctrl + \ 和 Ctrl + n

    5. 使用效果

    配置完成并重启 Neovim 后：

    • 按「空格 + t」在底部打开终端
    • 在终端中按 Esc 退出输入模式
    • 回到普通模式后，可以使用 Ctrl + w 切换窗口
    • 也可以输入 :q 关闭终端窗口

    6. 小结

    • 临时打开终端：:term
    • 下方打开终端：:split | term
    • 右侧打开终端：:vsplit | term
    • 底部固定高度终端：:botright 10split | term
    • 推荐快捷键：<leader>t
    • 推荐退出方式：Esc
